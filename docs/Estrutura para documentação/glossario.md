<!-- Glossário de Termos Técnicos e de Varejo do Projeto -->

FEFO → Regra que determina que o produto com a validade mais próxima deve ser vendido primeiro.

Avaria → Produto danificado ou impróprio para venda.

Divergência de Estoque → Quando a quantidade física de um produto é diferente da registrada no sistema.

SLA → Meta de qualidade do serviço, como tempo de atendimento ou disponibilidade do sistema.

RTO → Tempo máximo que um sistema pode ficar parado após uma falha.

RPO → Quantidade máxima de dados que a empresa aceita perder em uma falha.

Timeout → Tempo limite que um sistema espera por uma resposta antes de cancelar a operação.

RBAC → Controle de acesso baseado no cargo ou função do usuário.

Logs → Histórico de ações realizadas no sistema.

Logs Imutáveis → Registros que não podem ser alterados ou apagados.

XML de Nota Fiscal → Arquivo digital que contém todas as informações de uma nota fiscal eletrônica.

ERP → Sistema que auxilia na gestão da empresa, incluindo vendas, compras e estoque.

WMS → Sistema utilizado para controlar operações de armazenagem e estoque.

Inventário → Contagem dos produtos existentes no estoque.

Reposição → Reabastecimento de produtos no estoque ou na área de vendas.

Ruptura de Estoque → Situação em que um produto acaba e não está disponível para venda.

Bipagem → Leitura do código de barras de um produto usando coletor ou scanner.

Curva ABC → Classificação dos produtos conforme sua importância nas vendas.

Giro de Estoque → Velocidade com que um produto é vendido e reposto.

Estoque Mínimo → Quantidade mínima que deve existir para evitar falta do produto.

Estoque Máximo → Limite ideal de armazenamento de um produto.

Ponto de Reposição → Quantidade que dispara uma nova compra ou reposição.

Quebra de Estoque → Perda de produtos por roubo, vencimento, dano ou erro operacional.

Saldo de Estoque → Quantidade disponível de um produto no sistema.

Movimentação de Estoque → Qualquer entrada, saída ou transferência de produtos.

Bloqueio de Estoque → Reserva de produtos que não podem ser vendidos ou movimentados.

Um glossário é um dicionário do projeto, criado para explicar de forma simples os termos técnicos, de negócio, logística e tecnologia utilizados pela equipe.
