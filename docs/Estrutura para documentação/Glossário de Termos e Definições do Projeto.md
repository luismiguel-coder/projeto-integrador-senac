FEFO (First Expire, First Out)
O que significa?

Significa "Primeiro que Vence, Primeiro que Sai".


XML de Nota Fiscal
O que significa?

É o arquivo digital oficial da Nota Fiscal Eletrônica (NF-e), contendo todas as informações da operação.


RTO (Recovery Time Objective)
O que significa?

É o tempo máximo aceitável para o sistema voltar a funcionar após uma falha.


RPO (Recovery Point Objective)
O que significa?

É a quantidade máxima de dados que a empresa aceita perder em um incidente.


SLA (Service Level Agreement)
O que significa?

É o Acordo de Nível de Serviço, que define metas e compromissos de atendimento.


Timeout
O que significa?

É o tempo limite de espera para uma operação ser concluída.


RBAC (Role-Based Access Control)
O que significa?

É um modelo de controle de acesso baseado em papéis ou perfis.


Bipagem
O que significa?

É a leitura de códigos de barras ou QR Codes utilizando coletor ou scanner.

Como é aplicado no sistema?


Avarias
O que significa?

São produtos danificados, estragados ou impróprios para venda.


Divergência de Estoque
O que significa?

Acontece quando a quantidade física é diferente da quantidade registrada no sistema.


RMS (Retail Management System)
O que significa?

É o sistema de gestão de operações de varejo.


TOTVS
O que significa?

É uma das maiores empresas de software de gestão empresarial do Brasil, fornecendo ERPs e soluções para varejo.


SKU (Stock Keeping Unit)
O que significa?

Código único que identifica um produto.


Picking
O que significa?

Processo de separação de produtos para atender pedidos.


Inventário
O que significa?

Contagem física dos produtos em estoque.


Endereçamento
O que significa?

Localização física de armazenamento dos produtos.


Transferência
O que significa?

Movimentação de produtos entre locais.


Ruptura
O que significa?

Falta de produto disponível para venda.


Reserva de Estoque
O que significa?

Quantidade separada para atender pedidos específicos.


Conferência Cega
O que significa?

Processo no qual o conferente não vê a quantidade esperada.


Rastreabilidade
O que significa?

Capacidade de acompanhar todo o histórico de um produto.
