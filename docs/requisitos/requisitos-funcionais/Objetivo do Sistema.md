Objetivo do Sistema

O objetivo do nosso sistema é reduzir as perdas de produtos, diminuindo
os prejuízos causados pelo vencimento de mercadorias e,
consequentemente, aumentando a lucratividade da empresa por meio de um
controle mais eficiente do estoque.

Processos Atuais

Atualmente, o sistema realiza o cadastro dos produtos solicitando
informações como lote, quantidade, data de entrada, data de vencimento e
valor do produto.

Após o cadastro, o sistema gera gráficos e relatórios que mostram a
situação dos produtos no estoque, incluindo:

- Quantidade de produtos próximos do vencimento;

- Valor estimado do prejuízo mensal;

- Valor estimado do prejuízo anual.

Entretanto, o sistema apresenta uma limitação importante **nem todos os
produtos são cadastrados**. Como consequência, as informações geradas
não representam todo o estoque, tornando o controle menos eficiente e
reduzindo a confiabilidade dos relatórios.

Processos Futuros

Como melhoria, o sistema será integrado ao processo de “bipagem”
realizado quando os produtos chegam às docas. Dessa forma, todos os
produtos serão cadastrados automaticamente no sistema, eliminando falhas
causadas pelo cadastro manual.

Além disso, o sistema será integrado ao caixa (PDV), permitindo que cada
venda seja registrada automaticamente. Assim, o estoque será atualizado
em tempo real, garantindo maior precisão no controle dos produtos e
fornecendo informações mais confiáveis para a tomada de decisão.
