## O que o sistema faz

Gerencimento de perdas.

### Permissões

- **Gerente**: 
  - Cadastrar estoquista e analista
  - Visualizar relatórios de vendas
  - Gerenciar estoque (ajustar entrada/saída)
  - Cadastrar/excluir produtos
  - Acompanhar desempenho dos colaboradores
  - Gerar relatórios financeiros
  - Configurar preços e promoções
  - Tem acesso total.

- **Estoquista**: 
  - Não pode cadastrar ninguém
  - Visualizar estoque
  - Registrar entrada/saída de produtos
  - Conferir validade dos produtos
  - Gerar relatório de inventário

- **Analista**: 
  - Não pode cadastrar ninguém
  - Visualizar relatórios de vendas
  - Visualizar relatórios financeiros
  - Analisar dados de desempenho da loja
  - Acompanhar desempenho dos colaboradores
  - Gerar relatórios personalizados
  - Visualizar estoque
